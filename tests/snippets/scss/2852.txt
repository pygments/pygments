Single-line comments in SCSS selectors and declarations, with URL and string controls.

---input---
a, // selector comment
b {
  color: red; // inline comment
  // after declaration
  background:url(http://example.com/a//b);
  background: URL(
    https://example.com/image.png);
  background: url(//example.com/image.png);
  background: url("https://example.com/a)b//c");
  background: url(https://example.com/a\)b//c);
  background: url(https://example.com/#{$name}//image.png);
  content: "escaped \" // literal";
  /* // block comment
   */ // after block comment
  width: 1px;
}
